# Resepika - Technical Specification

## 1. Project Overview

**Project Name:** Resepika  
**Type:** Static web application with in-memory database  
**Purpose:** A recipe collection website featuring recipes from @khairulaming Instagram, with full-text search and admin dashboard for content management.  
**Target Users:** Malaysian home cooks looking for recipes

---

## 2. Tech Stack

| Layer       | Technology                               |

| Framework   | React Router v7 (Vite-based)             |

## 3. Database Schema

### 3.1 Main Table: `recipes`

```sql
CREATE TABLE recipes (
  id SERIAL PRIMARY KEY,
  title VARCHAR(500) NOT NULL,
  post_url VARCHAR(500) NOT NULL,
  thumbnail VARCHAR(500) NOT NULL,
  created_at TIMESTAMP DEFAULT NOW()
);
```

### 3.2 Trigram Index: `pg_trgm`

```sql
-- Enable pg_trgm extension for trigram similarity search
CREATE EXTENSION IF NOT EXISTS pg_trgm;

-- Create gin index on title for fast trigram matching
CREATE INDEX idx_recipes_title_trgm ON recipes USING gin (title gin_trgm_ops);
```

The pg_trgm extension provides language-agnostic fuzzy matching, ideal for Malay recipes where stemming is not available.

### 3.3 Drizzle Schema (`app/db/schema.ts`)

```typescript
import { pgTable, serial, varchar, timestamp } from "drizzle-orm/pg-core";

export const recipes = pgTable("recipes", {
  id: serial("id").primaryKey(),
  title: varchar("title", { length: 500 }).notNull(),
  postUrl: varchar("post_url", { length: 500 }).notNull(),
  thumbnail: varchar("thumbnail", { length: 500 }).notNull(),
  createdAt: timestamp("created_at").defaultNow(),
});

export type Recipe = typeof recipes.$inferSelect;
export type NewRecipe = typeof recipes.$inferInsert;
```

### 4.2 Initial Load Sequence

1. App loads in browser
2. Pglite initializes (PostgreSQL WASM, in-memory)
3. Execute bundled `seed.sql` → Create tables → Insert data
4. Render UI with data from Pglite
5. On page refresh: Start fresh (no persistence)

## 6. Public Routes

### 6.1 Home Page (`/`)

**Components:**

- Header with title and Instagram link
- Search input (debounced, 300ms)
- Recipe grid (responsive: 1 col mobile, 2 col tablet, 3 col desktop)
- Affiliate links section
- Footer

**Search Behavior:**

- Real-time filtering as user types
- Case-insensitive matching via pg_trgm trigram similarity
- Results ordered by relevance (similarity score)

**Data Loading:**

- Client-side query via Drizzle
- On mount: `SELECT * FROM recipes ORDER BY created_at DESC`

### 6.2 Filtered Page (`/:term`)

**URL Pattern:** `/ayam`, `/nasi-goreng`, `/kek-pisang`

**Behavior:**

- Pre-filter recipes matching term in title
- Same grid component as home
- Search input shows current filter

**Implementation:**

- Get `term` from URL params
- Query: `SELECT * FROM recipes WHERE title ILIKE '%ayam%'`

## 10. API Reference

### 10.1 Database Client (`app/db/index.ts`)

```typescript
import { PGlite } from "@electric-sql/pglite";
import { drizzle } from "drizzle-orm/pglite";

// Initialize Pglite in-memory (no persistence)
export const pglite = new PGlite();

// Wrap with Drizzle
export const db = drizzle({ client: pglite });
```

### 10.2 Recipe Queries

```typescript
// Get all recipes
const allRecipes = await db.select().from(recipes).execute();

// Search recipes (pg_trgm - language agnostic, great for Malay)
const searchResults = await db.execute(
  `SELECT *, similarity(title, $1) as sim 
   FROM recipes 
   WHERE title ILIKE $2
   ORDER BY sim DESC`,
  [query, `%${query}%`]
);

// Alternative: Use ILIKE only (simpler, still works well)
const simpleSearch = await db.execute(
  `SELECT * FROM recipes WHERE title ILIKE $1`,
  [`%${query}%`]
);

// Add recipe
await db
  .insert(recipes)
  .values({
    title: "New Recipe",
    postUrl: "https://...",
    thumbnail: "https://...",
  })
  .execute();

// Delete recipe
await db.delete(recipes).where(eq(recipes.id, id)).execute();
```
